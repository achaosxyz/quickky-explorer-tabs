# Quickky Explorer Tabs

[English](README.md) | [简体中文](README.zh-CN.md)

为 Windows 文件资源管理器提供统一的多标签工作区，将新打开的文件夹窗口自动收进同一处。

> **目前尚不可使用。** 项目处于初始化阶段，还没有可运行的应用或安装包。下面介绍的是目标体验，不代表功能已经实现。

## 功能体验

- **文件夹集中管理。** 新打开的文件资源管理器文件夹窗口自动加入同一个标签工作区，不再分散成多个独立窗口。
- **保留熟悉的资源管理器。** 继续使用 Windows 文件资源管理器浏览文件夹，无需换用另一款文件管理器。
- **Win10 / Win11 统一标签体验。** 使用 Quickky 自己的标签功能，外观参考 Win11 原生样式。在 Win11 上替代系统自带的标签控件，而不是再叠加一排标签。
- **中英文管理界面。** 管理页面支持英文和简体中文是项目的功能目标。

## Windows 支持范围

面向 x86_64 电脑上的 Windows 10 和 Windows 11，具体系统版本尚未验证。

工作区只管理当前虚拟桌面上的资源管理器文件夹窗口，不接管桌面、任务栏，以及“打开／保存”文件对话框。

## 开始使用

目前没有可安装或启动的程序。可用版本发布后会提供安装与使用说明；现阶段无需为本项目修改资源管理器配置。
